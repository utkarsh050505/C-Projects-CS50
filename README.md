# 💻 CS50x Projects Portfolio

This repository showcases my solutions to several core projects from the [CS50x: Introduction to Computer Science](https://cs50.harvard.edu/x/) course by Harvard University. Each project demonstrates an understanding of foundational programming concepts using C, memory management, algorithms, and command-line utilities.

---

## ✅ Completed Projects

### 1. **Credit**
- **Description**: Implements Luhn’s Algorithm to validate credit card numbers (Visa, MasterCard, Amex).
- **Tech Stack**: C, Command Line
- **Concepts**: Arithmetic, Loops, Conditionals, Algorithm Implementation

---

### 2. **Filter - More**
- **Description**: Applies grayscale, sepia, reflect, and blur effects to bitmap images.
- **Tech Stack**: C, BMP File Format, Image Processing
- **Concepts**: 2D Arrays, Image Manipulation, Structs, Pointer Arithmetic

---

### 3. **Inheritance**
- **Description**: Simulates genetic inheritance of blood types across generations using recursion.
- **Tech Stack**: C
- **Concepts**: Recursion, Memory Allocation, Structs

---

### 4. **Plurality**
- **Description**: Simulates a simple election using plurality voting method.
- **Tech Stack**: C
- **Concepts**: Arrays, Structs, Command-Line Arguments

---

### 5. **Population**
- **Description**: Calculates the number of years required for a population to reach a target size using a loop.
- **Tech Stack**: C
- **Concepts**: Loops, Mathematical Modeling, Conditionals

---

### 6. **Recover**
- **Description**: Recovers JPEG images from a raw memory card image file.
- **Tech Stack**: C, File I/O, Hex Inspection
- **Concepts**: File Streams, Buffering, Memory Layout

---

### 7. **Runoff**
- **Description**: Implements a runoff voting system using ranked-choice ballots.
- **Tech Stack**: C
- **Concepts**: Arrays, Dynamic Voting, Elimination Rounds, Logic Handling

---

### 8. **Speller**
- **Description**: Implements a spell checker using hash tables and compares performance metrics.
- **Tech Stack**: C, Hash Tables, Dictionary Files
- **Concepts**: Data Structures, File I/O, Memory Efficiency, Benchmarking

---

### 9. **Substitution**
- **Description**: Encrypts plaintext using a monoalphabetic substitution cipher.
- **Tech Stack**: C
- **Concepts**: Arrays, Strings, Command-Line Args, ASCII Manipulation
